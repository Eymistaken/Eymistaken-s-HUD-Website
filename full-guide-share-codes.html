Layouts

Share codes

Your whole HUD, packed into one line of text you can paste into a chat. Codes start with EYMHUD1-. Your best combo stays behind: it is not a setting, so no code carries it.

Two kinds of code

PropertyFull config codeKeystrokes code
CarriesEvery setting of every module, third-party ones included, but not your best comboThe whole Keystrokes look
Export fromThe settings screen, or the editor's Export CodeThe Designer's EXPORT
Import atThe settings screen, or the editor's Import CodeThe Designer's IMPORT
Backup takenYes: a timestamped preset, before anything is appliedNo: the Designer's undo covers it

The two are not interchangeable, and giving one to the wrong screen is refused rather than half-applied: paste a keystrokes code into the settings screen and it tells you to use the Designer instead.

What a keystrokes code carries

The layout and the look: the design, the animations and their direction, the release trail, the board, the scale, the rainbow settings and all four colors, including anything a single key overrides on its own.

Where it sits on your screen is left out on purpose. A shared design should not move your HUD into someone else's corner, so the anchor and the offsets stay yours.

Limits and errors

A code is a string from a stranger, so every step of reading one is bounded: 64 KB of text at most, 512 KB once unpacked, and a hard stop before anything larger is allocated. A malformed or oversized code is rejected outright, and nothing is partly applied.

Not a valid share codeThe text is malformed, too large, or was made by a newer version of the mod than yours.
No valid code in clipboardYou pressed Import with an empty field and nothing usable on the clipboard.
That's a keystrokes codeRight code, wrong screen: take it to the Designer.
That's a config codeThe mirror image: take it to the HUD editor.
Imported from v1.2.0It worked, but the code came from a different version of the mod. Worth a glance to check nothing looks off.

Codes from older versions still import. Keystrokes codes made before 1.2.1 carry no look of their own and arrive wearing your design. Codes exported from 1.2.1 on are refused by earlier builds, so someone still on 1.2.0 needs to update before your layout reaches them.

1.2.3 drew the same line again, for a different reason. Minecraft 26.3 renumbered keys and mouse buttons, so a code written by 1.2.2 or earlier has its key numbers translated on the way in, while a 1.2.3 code is refused outright by older builds rather than applied to the wrong keys.
