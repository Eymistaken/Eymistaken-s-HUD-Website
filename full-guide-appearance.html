Layouts

Outline and menu scale

Two settings on the General page's Display tab. Both apply to every module at once.

Text outline

SettingDefaultWhat it does
Text OutlineOffOff gives Minecraft's usual drop shadow. On draws a thin black outline on every side instead, which reads much better over bright terrain and snow.

Third-party modules that draw their text through the API's drawText follow this setting too.

Menu scale

The settings screen already holds one physical size across every Minecraft GUI Scale. Menu Scale % nudges that baseline if you want the menus larger or smaller than the mod's own idea of right.

SettingDefaultRangeWhat it does
Menu Scale %10050–200Size of the mod's own menus, relative to the size they keep at any GUI Scale.

Font

The HUD and the mod's own screens always draw in Minecraft's own font. Up to 1.2.4 a HUD Font setting offered Inter, Rubik, JetBrains Mono, Bebas Neue and the enchanting-table font, but they rendered blurry at HUD sizes, so 1.2.5 removed the setting and the fonts with it.

A config that had one selected loads unchanged and draws in vanilla. The Restore Font button went with them, since there is nothing left to restore.
