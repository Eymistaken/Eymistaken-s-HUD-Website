Install

  1. 1

    Install Fabric Loader 0.19.5 or newer from fabricmc.net.

  2. 2

    Install Fabric API, the build for Minecraft 26.3: 0.160.6+26.3 or newer. It is the only dependency.

  3. 3

    Download the latest Eymistaken's HUD .jar from Modrinth, CurseForge or GitHub Releases.

  4. 4

    Drop every .jar into .minecraft/mods/ and launch the game.

  5. 5

    Press Right Shift in game to open the HUD editor. The settings screen is under Options → Mods → Eymistaken's HUD → Settings, or in the editor's global menu.

Next: the User Guide walks through the editor in five minutes.

Mod Menu is optional

It only adds a button that opens the settings screen from the title screen. Everything it reaches is also in the editor's global menu.
