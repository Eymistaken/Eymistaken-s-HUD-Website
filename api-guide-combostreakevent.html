ComboStreakEvent

Fired when a counted hit pushes the combo into a higher heatmap tier: once per tier, not once per hit.

public record ComboStreakEvent(int combo, int level, int previousLevel, Entity target), in com.eymistaken.simplecps.api.event, since 1.2.0. This page also covers ComboHeatmap, the tiers behind its levels.

Components

int combo()since 1.2.0

The combo count after this hit.

int level()since 1.2.0

The tier it just reached, 1 to 3.

int previousLevel()since 1.2.0

The tier it was in before.

Entity target()since 1.2.0

The entity that was hit. Never null.

When it fires

On the hit that reaches a tier, compared around the increment, so a tier is announced once. It follows counted hits: since 1.2.2 a hit counts once the server confirms it by default, so with Hit Detection on Server the event waits for that confirmation too.

It fires whether or not heatmap coloring is on. That setting decides how the counter looks, not whether the streak happened.

ComboHeatmap

public record ComboHeatmap(int tier1, int tier2, int tier3), in com.eymistaken.simplecps.api, since 1.2.0. The thresholds behind the levels, shared so the display and the event can never disagree about what level 2 means.

static ComboHeatmap of(SimpleCPSConfig.HeatmapMode mode)since 1.2.0

The tiers for a Heatmap Difficulty. Easy, Medium and Hard are fixed. Custom, since 1.2.2, reads the player's own three tiers from the config on every call and puts them in order. A mode this build does not know gives Medium.

int levelFor(int combo)since 1.2.0

The level for a count: 0 below tier1, 1 up to tier2, 2 up to tier3, and 3 at or above it, which is also where the counter starts to shake.
