Placement and layout

Every module gets the same four placement rows on its Position tab, and third-party modules get them too.

The placement rows

SettingDefaultRangeWhat it does
PositionTop left5 anchorsAn anchor grid. The corner, or the center, the module is placed from.
X Offset0−10000–10000 pxA stepper. Horizontal distance from the anchor.
Y Offset0−10000–10000 pxA stepper. Vertical distance from the anchor.
Scale %10050–300A slider. The scroll wheel in the editor changes it too.

The anchor grid is 3 by 3, but only five cells do anything: the four corners and the center. The four edge cells are inert.

Two modules start elsewhere. The Armor HUD starts in the bottom left, and Keystrokes at 80% scale.

Auto-stacking and manual placement

Modules that share a corner are stacked along that edge automatically, so they never sit on top of each other. A module leaves auto-stacking the moment you give it a non-zero offset or drag it in the editor. From then on it is placed exactly where you put it, clamped to the screen, and the stack closes up behind it.

Centered modules are centered rather than stacked, so two of them can overlap unless you offset one.

Prevent OverlapOn by default. Pushes colliding modules to the nearest free spot, so two of them never cover the same pixels. It is on the General page's Editor tab.
