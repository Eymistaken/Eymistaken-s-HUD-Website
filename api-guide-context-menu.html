Settings

Context menu

When a player right-clicks your module in the HUD editor, a context menu opens. Extend it by overriding getContextMenuSettings().

By default it holds Reset Position, Reset Settings and Open Settings. Keep it short: it is the quick reach, not the full panel, and everything you put in it also shows on your module's settings page.

The six setting types

All six live in com.eymistaken.simplecps.api. Their constructors are on the HudModuleSetting reference.

BooleanSettingAn [ON] or [OFF] toggle.
ColorSettingA color swatch that opens the color picker.
TextSettingShows the current value and opens an inline text field.
CycleSettingSteps through a fixed list of options on each click.
ActionSettingA plain button with no value. Since 1.2.5 it can tint its label, to mark a row that opens something rather than changing a value.
SliderSettingA draggable integer slider with a live value and a Reset button. Takes a minimum, a maximum and a default.

All six in one menu

Keep the super call. Calling super.getContextMenuSettings() and copying it into a new ArrayList keeps the default Reset Settings row at the top of the menu. Leave it out only to replace that row on purpose. Reset Position is there either way: the editor adds it, not getContextMenuSettings().

What Reset Settings does

Override resetVisualDefaults() to define it for your module. Reset visual and behavioral fields, and leave the enabled state and the offsets to the player. If your module treats scale as a visual preference it is safe to reset it here, as the built-in modules do.

**Never reset enabled, the anchor or the offsets here.** Position belongs to Reset Position, and whether the module is on is always the player's choice.
