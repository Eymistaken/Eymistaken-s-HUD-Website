Quick start

Three files take an empty Fabric mod to a module that is ticked and drawn alongside the built-in seven, with a page of its own in the settings screen. No core modification required.

Written against Eymistaken's HUD 1.2.5 on Minecraft 26.3 and Java 25. Every public type lives in com.eymistaken.simplecps.api.

Safe to build on. Every hook added since the API first shipped in 1.1.0 comes with a default, so an addon compiled against an older release keeps running on a newer one.

Step 1

Add the dependency

The API is published through JitPack. Add the repository and the dependency, then reload Gradle.

repositories {
    maven { url 'https://jitpack.io' }
}

dependencies {
    implementation 'com.github.Eymistaken:Eymistaken-s-HUD:main-SNAPSHOT'
}
repositories {
    maven("https://jitpack.io")
}

dependencies {
    implementation("com.github.Eymistaken:Eymistaken-s-HUD:main-SNAPSHOT")
}

implementation, not modImplementation. Minecraft 26.x ships unobfuscated and Loom no longer remaps mods, so the mod-specific configurations are gone and modImplementation fails with "configuration not found".

To pin a fixed build, put a release version in place of main-SNAPSHOT, without the leading v; JitPack strips it from the tag. The latest release says which one that is.

Step 2

Write the module

Extend HudModule and implement its eight abstract methods. This is the minimum.

Return a real size. getWidth() and getHeight() drive stacking. Returning 0 removes the module from the layout and makes it invisible.

Names are keys. getName() keys your layout flags and saved state. registerModule() refuses a name that is taken and logs an error; check first with manager.isNameTaken(String).

Step 3

Register the plugin

Implement EymistakenHudPlugin and declare it under the eymistaken_hud entrypoint.

Start the game with your addon and Eymistaken's HUD installed. Your module draws at its anchor and gets its own page in the settings screen, listed under PLUGINS. Plugins are discovered after the config is read, so stored state is replayed into your module the moment it registers.

What HudModule asks of you

The eight abstract methods. Everything else on the class has a default; see the full reference.

String getName()since 1.1.0

Unique key for your layout flags and saved state. Prefix it with your mod id.

SimpleCPSConfig.Position getPositionType()since 1.1.0

The anchor: one of the four corners, which stack automatically, or CENTER, which is centered rather than stacked.

int getXOffset()
int getYOffset()since 1.1.0

Offset from the anchor in pixels. Any non-zero offset takes the module out of auto-stacking.

boolean isEnabled()since 1.1.0

Whether the module renders at all. Tie it to your own config.

int getWidth()
int getHeight()since 1.1.0

The size of what you draw, with scale applied. Used by stacking, the editor and the preview card.

void extractRenderState(GuiGraphicsExtractor context, float tickDelta)since 1.1.0

Draw here. Translate to this.x and this.y, then draw from the local origin.
