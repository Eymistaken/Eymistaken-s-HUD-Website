Installation

  1. 01 Install Fabric Loader 0.18.4 or newer from fabricmc.net.
  2. 02 Install Fabric API. It is the only dependency.
  3. 03 Download the latest Eymistaken's HUD .jar from Modrinth, CurseForge or GitHub Releases.
  4. 04 Drop every .jar into .minecraft/mods/ and launch the game.
  5. 05 Press Right Shift in game to open the HUD Editor, or reach the settings screen from Options → Mods → Eymistaken's HUD → Settings, or from the editor's global menu.

Optional

Mod Menu

Mod Menu only adds a button that opens the settings screen from the title screen — module toggles, colors, positions and scales. Everything it reaches is also reachable from the editor's global menu, so it is a convenience, not a requirement.
