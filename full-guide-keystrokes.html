Modules

Keystrokes

The key display. These are the settings for the whole cluster; anything about a single key lives in the Keystrokes Designer.

Off by default, and at 80% scale rather than 100%, because the stock cluster is large. Four tabs: Style, Animation, Background, Layout. In the editor's right-click menu: Enable Keystrokes, Design, Board, Open Designer. This module has no Reset Settings row. The layout holds up to 256 keys.

Style

SettingDefaultRangeWhat it does
Text ColorWhiteColor of the key labels at rest.
Pressed ColorGreenColor used while a key is held.
RainbowOffCycles the colors through every hue.
Rainbow TargetTextText, BackgroundWhether the rainbow paints the labels or the key bodies.
DesignBaseline11 designsThe look of a key at rest. Picking one also applies its animation and palette; see the design catalog.

Design is not just a texture. Choosing one rewrites your animations, all four colors and, for Wedge and Hex, the positions of your keys. Everything stays editable afterwards, but export your layout first if you have one you want to keep.

Animation

SettingDefaultRangeWhat it does
Fill DirectionRight8 directionsWhich side a directional fill starts from. Fills with no direction ignore it.
Release TrailOffLeaves a fading outline behind when you let a key go.
BoardOffFrames the whole cluster with an ornamented board.

Which motions and fills run is not set here. They are a set, and only the Designer's animation drawer can tick a set; see the animation system.

Background

SettingDefaultRangeWhat it does
Background ColorBlackColor of the key bodies.
Background Opacity1280–2550 is invisible, 255 is solid.

There is no Show Background toggle. Set Background Opacity to 0 to remove the key bodies and leave only the labels. That is how the Frame, Bar and Segment designs get their look.

Layout

The Layout tab holds one button, Keystroke Designer, which opens the Designer. Every key's position, size, label, keybind and colors are set there.
